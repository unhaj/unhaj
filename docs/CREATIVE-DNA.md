# Creative DNA

BrandForge V21 composes each website from independent design decisions rather than a single fixed template.

- **hero**: full-bleed
- **nav**: glass-bar
- **cards**: hard-grid
- **grid**: editorial-columns
- **type**: humanist
- **motion**: reveal
- **media**: diagrammatic
- **composition**: catalog-first
- **spacing**: balanced
- **shape**: cut-corner
- **pageLayout**: sidebar
- **footer**: utility
- **architecture**: dashboard
