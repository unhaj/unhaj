# Commerce Setup

The generated store is **commerce-ready but not a fake live store**. Before enabling purchases, connect:

1. Real catalog and variants
2. Verified prices and inventory
3. Hosted checkout / payment provider
4. Tax configuration
5. Shipping and fulfillment
6. Returns policy
7. Order management
8. Customer support

Never collect card details directly in a static GitHub Pages form. Use a real PCI-compliant hosted checkout or commerce backend.
